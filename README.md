# SketchTools

**SketchUp-style precision drawing tools for Blender.**

SketchTools brings fast and intuitive drawing workflows to Blender's 3D Viewport, with an emphasis on precision, snapping, inference and direct geometry creation.

## SketchTools Free 1.0

The Free edition includes five core drawing tools:

- **Line** — Continuous precision line drawing with snapping and inference
- **Rectangle** — Quickly create rectangular geometry with live dimensions
- **Circle** — Create circles with adjustable segment count and live radius
- **Freehand** — Smooth freehand drawing on surfaces
- **Eraser** — SketchUp-style click-and-drag geometry erasing

## Features

- Native Blender toolbar integration
- Custom SketchTools toolbar icons
- Live measurements while drawing
- Exact line-length input
- X, Y and Z axis inference
- Same-axis grid snapping
- Endpoint and midpoint snapping
- Equal-length inference
- Surface-aware snapping
- Occlusion-aware snapping
- Object Mode drawing
- Edit Mode geometry cutting
- Circle segment adjustment
- Smooth surface Freehand drawing
- Orbit and zoom while drawing

## Compatibility

**Blender 4.2 LTS and later**

SketchTools Free 1.0 has been developed and tested with Blender 4.2 LTS.

## Installation

1. Download the latest SketchTools Free release.
2. Open Blender.
3. Go to **Edit → Preferences → Extensions**.
4. Open the Extensions menu and choose **Install from Disk**.
5. Select the downloaded SketchTools ZIP file.
6. Enable SketchTools if required.
7. The SketchTools drawing tools will appear in Blender's left-hand 3D Viewport toolbar.

## Usage

Select one of the SketchTools icons from the 3D Viewport toolbar and begin drawing.

SketchTools supports precision measurements, snapping and inference while you work.
